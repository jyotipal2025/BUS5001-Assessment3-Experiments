# Q3 – ESG Message Triage

This folder contains experiment logs and evidence for Question 3 of BUS5001 Assessment 3.

The experiment compares:
- LLM-based ESG message classification
- Hugging Face zero-shot classification
- consistency and confidence across test messages
- proposed Azure cloud architecture for operational deployment

Test messages include:
1. Water leak in Building C
2. Accessible entrance blocked for two days
3. Supplier sustainability policy concern
